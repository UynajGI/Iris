# Contributing to Iris

Report reproducible bugs and propose features through [Issues](https://github.com/UynajGI/Iris/issues). Include your Iris version, operating system, architecture and reproduction steps. Use synthetic or shareable photographs; remove personal paths, tokens and database contents from attachments.

For code or documentation changes, fork the repository, create a focused branch and open a pull request describing the resulting behavior and relevant checks. Follow the [development and contribution guide](docs/contributing.md) for setup, tests, Conventional Commits and public-source checks. The detailed guide is currently in Chinese; runnable commands and paths are unchanged across languages.

Iris-owned contributions use GPL-3.0-or-later. Preserve third-party licenses and notices, and contribute only material you have permission to share. Document unrun tests rather than reporting them as passed.

Report security vulnerabilities through the private channel in [SECURITY.md](SECURITY.md), rather than a public issue. Creator and contributor information is in [AUTHORS.md](AUTHORS.md).
