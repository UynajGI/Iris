# Iris v0.1.0-beta4

beta4 基于已发布 beta3，继续打磨本地选片。当前为 `codex/beta4-selection` 分支的源码升级与本机验证记录，安装包尚未发布。

## 本次变化

- 浏览当前照片、比较照片和相邻照片时，待处理分析优先跟随浏览位置，同时保留后台进度。
- 常用筛选、评分/日期/大小/名称排序先在数据库分页，避免为一页载入整库人脸和向量。
- 原图区域按需复核并独立缓存；明确显示原始细节、仅预览和不可测量的区别。
- 场景、连拍与重复文件分离；场景支持合并所选、拆出当前照片、恢复自动分组并持久保存人工修正。
- 比较支持参考照片、评分差异、可确认的人脸对应候选、联动或独立缩放和平移，保留键盘取舍。
- 可选本地图文搜索具有真实双编码器推理、分词、持久索引、取消和指纹失效；默认关闭，需自行准备有权使用的兼容模型，见[指南](../local-search.md)。
- 检测、质量权重重算、细节和检索缓存保持不同依赖，修改质量权重不重建细节和检索向量。

## 本机证据与边界

一万条合成分析记录、100 项分页，中位数 31.1ms；先完整载入再排序的行为对照为 2173ms，结果一致。这是查询策略对照，不是完整 beta3/beta4 安装包的通用速度比。

541 张 PPR 衍生缩小 JPEG：CPU 基础分析约 38.6 张/秒，冷预览服务响应 P95 64ms；浏览器分析期间切图 P95 73ms、冷切图 P95 137ms。单机单轮，文件系统缓存未控制，不推广至全分辨率 RAW 或其他设备。完整方法见[性能记录](../performance-plan.md)。

后端 workspace 222 通过、23 默认忽略；另显式验证合成 ONNX 双编码器和一万条查询测量。前端 108 通过、1 跳过，公开人像定向浏览器流程通过。最终门禁与保留问题见[验证总览](../validation.md)。

RAW/HEIC 原始区域尚未测量；几何人脸对应不是身份识别；场景候选未有独立人工金标。真实检索模型的语言与摄影语义质量待评估，文本查询仍有模型冷启动成本，精确扫描的大图库延迟尚未验收。beta3 的 ORT API 21 与平台清理修复保持，未修改运行库版本或默认模型许可。

beta4 的跨平台构建、干净系统安装、升级、签名和原生 WebView2 性能尚待验证；本机源码检查不等于发行成功。
