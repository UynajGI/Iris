# Iris v0.1.0-beta2

本次 Beta 更新桌面界面与全局对齐，加入各平台原生安装包，并修复模型路径与诊断日志的安全问题。
旧版 `v0.1.0-beta` 的 Tag 和附件保持不变；请重新下载 beta2，勿沿用旧版校验和。

## 下载与安装

| 系统 / 处理器 | 推荐安装包 | 安装方式 |
| :--- | :--- | :--- |
| Windows x64 | `Iris-0.1.0-beta2-windows-x64-setup.exe` | 运行当前用户安装向导；需要 WebView2 与 VC++ 2015–2022 x64 Runtime |
| macOS Apple Silicon | `Iris-0.1.0-beta2-macos-arm64.pkg` | 打开 PKG，跟随系统 Installer 安装到 `/Applications/Iris.app` |
| macOS Intel | `Iris-0.1.0-beta2-macos-x64.pkg` | 同上；与 Apple Silicon 安装包不可混用 |
| Ubuntu / Debian x64 | `Iris-0.1.0-beta2-linux-x64.deb` | 软件安装器或 `sudo apt install ./Iris-0.1.0-beta2-linux-x64.deb` |

各平台继续提供 ZIP / tar.gz 便携包。`source.zip` 与此版本提交对应；下载后使用
`SHA256SUMS.txt` 核对文件。实际附件与构建状态以此版本 GitHub Release 和 Actions 为准。

## 本次变化

* 桌面界面、布局对齐、主题与动效改进；Windows 安装向导和 macOS 安装资源随源码构建。
* Release CI 要求四个平台的安装包、便携包、源码闭包与校验和完整后才创建草稿。
* 模型读写统一限制在选定根目录内，拒绝子路径穿越、符号链接和 Windows junction / reparse point；诊断不输出凭据内容或动态规则标签。
* git-cliff 自动生成分类变更记录；安装说明和已知限制单独维护，版本号不会自动提高。

## 已知边界与测试建议

* **未正式签名或公证**，不配置自动更新。macOS 系统可能要求在“隐私与安全性”确认打开。
* Windows 包含 HEIC/HEIF、ExifTool 和独立 RAW 转换器；macOS/Linux 暂不包含 HEIC 与 ExifTool。Linux 基线为 Ubuntu 22.04、GTK 3 和 WebKitGTK 4.1。
* 默认 CPU 推理；可选研究模型不随安装器分发，不自动接受许可或启用 GPU。
* CI 构建、包内推理与安装载荷检查不替代干净系统上的视觉、原生交互和真实版本升级验收。
* 尚无独立人工标注的准确率保证。使用授权照片副本，重点测试启动、扫描、标记、导出、取消与恢复。

照片和推理保留在本机。标记淘汰不会删除原图；隔离和导出需要明确操作。
