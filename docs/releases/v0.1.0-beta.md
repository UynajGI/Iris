# Iris v0.1.0-beta

首个公开 Beta，面向 Windows、macOS 和 Linux 的实际使用测试。此版本提供桌面选片、CLI 和 stdio MCP；照片与推理保留在本机。

## 下载与运行

* Windows x64：解压 ZIP，在解压目录运行 `powershell -NoProfile -File .\Launch.ps1`。需要 WebView2 与 VC++ 2015–2022 x64 Runtime。
* macOS：选择 arm64（Apple Silicon）或 x64（Intel），解压 tar.gz，打开 `Iris.app` 或在解压目录运行 `bash Launch.command`。应用未签名公证，系统可能要求用户在隐私与安全设置中确认打开。
* Linux x64：解压 tar.gz，在解压目录运行 `bash Launch.sh`。目标基线为 Ubuntu 22.04，系统需安装 GTK 3 和 WebKitGTK 4.1。
* `source.zip` 为该 Tag 对应的源码；`SHA256SUMS.txt` 校验发行附件。各包保留默认模型许可与对应源码材料。

## 测试重点

请优先检查启动、原生目录选择、缩放与字体、扫描与分析、批量标记、CSV/XMP 导出、取消任务、重启恢复，以及 MCP 接入。反馈时提供系统版本、处理器架构、照片格式、操作步骤和错误信息；默认不要附私人照片、数据库或含本机路径的完整日志。

## 已知边界

* Windows 包含 HEIC/HEIF 运行库、ExifTool 和独立 RAW 转换器。macOS/Linux 暂未打包 HEIC 与 ExifTool；JPEG/PNG/WebP 可用于完整 CPU 工作流，RAW 后备转换有 24MP 开发上限。
* 发布包使用 CPU。DirectML 仅 Windows 可选准备；macOS GPU、Linux GPU 及 DINO GPU 全流程不在本次包的支持承诺中。DINO/SCRFD 等可选权重不随包分发。
* 不提供签名安装器或自动更新渠道。CI 构建和推理测试不能替代不同电脑上的原生交互、色彩管理与真实图库验收。
* 评分尚无独立人工标签校准；HEIC HDR/ICC 精度、3000 独立场景和广泛 RAW+JPEG 相机配对仍待验证。

使用授权照片副本开始测试。标记淘汰不删除文件；隔离与导出是需要明确操作的独立流程。
