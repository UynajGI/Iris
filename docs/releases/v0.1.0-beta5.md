# Iris v0.1.0-beta5

beta5 汇总 beta4 源码阶段的选片改进，并补齐安装界面、帮助诊断和日常操作。当前为源码版本，
安装包尚未发布；已发布下载仍以 [Releases](https://github.com/UynajGI/Iris/releases) 为准。

## 本次变化

- 常用筛选组合可命名保存、跨项目应用和删除；应用时重置到当前项目第一页，不携带原项目的照片或场景。
- 复制、CSV、XMP 导出成功后提供“打开文件夹”；CSV 打开所在目录，XMP 打开项目原片目录。
- “帮助与关于”集中版本、构建信息、离线帮助、快捷键、许可与手动下载入口。
- 本地日志限制体积并轮转；可导出不含照片、路径、数据库和凭据的诊断信息，错误可展开查看并复制脱敏摘要。
- Windows 安装与卸载向导统一深色控件，简化完成页；原生安装器由发行 CI 构建。
- 版本号由单一来源同步到 Cargo、前端、Tauri 和锁文件，CI 检查一致性。
- 继承 beta4 的浏览优先分析、数据库分页、场景修正、原图区域复核、组内保留意图、必留锁定、
  主角对应纠正、选片位置恢复和可选本地图文检索。详细范围见 [beta4 源码记录](v0.1.0-beta4.md)
  与[选片功能补齐计划](../selection-workflow-plan.md)。

## 使用与升级

源照片保持原位置；标记剔除不会删除照片，隔离操作仍需明确确认。复制导出会生成副本，
XMP 保留已有调色字段。升级前退出应用并备份应用数据目录；照片原件需另行保管。
使用方法与诊断范围见[帮助说明](../support.md)。

自动更新默认关闭。可选模型不自动下载或接受许可；当前没有因升级版本而新增运行时依赖。
源码升级、PR 检查通过与安装包发布是不同阶段，下载附件以对应 Release 为准。

## 验证与已知边界

新增功能本地验证：前端 135 项通过、1 项原有 live 检查跳过，类型检查、前端构建和提交质量门禁通过。
合成状态的浏览器检查覆盖筛选组合持久化、重名保护、应用/删除、导出成功/失败及目录入口；
帮助页另覆盖离线内容、诊断导出提示与版本复制。两种窗口尺寸为 1440×960 和 800×560，未使用个人照片。

本轮未在本机编译 Rust。新日志和目录校验的 Rust 测试、宿主编译由 PR CI 验证；
模拟原生桥的浏览器测试不等同于系统对话框、文件管理器及完整安装器的原生验收。
beta5 安装包、干净系统升级、签名、公证与跨平台视觉验收仍待完成。

历史性能数据及适用范围见[性能记录](../performance-plan.md)，不作为 beta5 全分辨率 RAW 或其他机器的速度承诺。
模型准确率、HEIC 原图细节与可选检索模型的边界继续以[交接文档](../HANDOFF.md)为准。
