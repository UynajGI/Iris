# Iris v0.1.0-beta3

beta3 聚焦连续选片的速度和桌面使用体验。发行附件及跨平台结果以对应 GitHub Release / Actions 为准；下面记录源码改动和本机证据。

## 本次变化

- 预览解码移出共享服务锁，当前照片优先；缩略图与预取有界调度，屏外照片延迟读取，快速切图取消过时任务。
- 导入并行读取尺寸与拍摄信息，首项及后续批次独立提交；普通画册先在 SQL 中分页再读取分析内容。
- 基础评分先可用，DINO 候选分组继续后台处理；CPU 有界并行。完整 DirectML 运行库缺失时恢复 CPU 并行，任务详情显示实际回退。
- 固定使用 ONNX Runtime 兼容 API 21，避开 `ort rc.13` 默认自动设备选择在 Unix CPU 运行库中的崩溃路径；CPU 与 DirectML 仍按应用配置选择。
- 组内技术比较、人脸原图局部检查、结构化判断依据、即时标记、缩放与示波器体验随当前选片工作台保留。
- Windows 原生窗口按钮与深色顶栏合并；关闭可选择后台运行或退出并记住偏好，托盘可重新打开，退出保留未保存参数保护。macOS/Linux 保留系统窗口装饰。

## 本机速度证据

Ryzen 9 7940HS、16 逻辑 CPU、Windows GNU release，541 张 PPR 来源的缩小 JPEG 人像，两轮基础配对测量：

| 项目                         | 基线            | beta3 改动构建  |
| :--------------------------- | :-------------- | :-------------- |
| 导入全部照片                 | 6.18–7.60 秒    | 0.81–1.06 秒    |
| 后台加载缩略图时前台预览 P95 | 378–612 毫秒    | 43–45 毫秒      |
| 基础分析吞吐                 | 22.5–27.9 张/秒 | 28.7–29.0 张/秒 |

浏览器首次/缓存首屏约 2.24/1.06 秒，分析期间切图 P95 117 毫秒，打星显示约 40 毫秒。仍有最高 102 毫秒的主线程长任务，冷切图有波动。应用缓存全新，文件系统缓存和温度未控制；这些结果不能推广到全分辨率 RAW、其他机器或原生 WebView2。吞吐的少量重复不足以建立通用推理加速结论。完整方法、DINO 与 GPU 批量输入限制见[性能验收](../performance-plan.md)。

## 验收与使用边界

- 本机检查与忽略项见[验证总览](../validation.md)；已有 beta2 四平台发行证据不能代替 beta3 的构建、安装和升级验收。
- 默认 CPU 模型继续随发行载荷提供；可选研究模型独立安装并核对许可，不自动启用或接受许可。
- Windows 包含的 HEIC/ExifTool/RAW 范围、macOS/Linux 的媒体运行库缺口见[媒体支持](../media-support.md)。正式签名、公证与自动更新仍未配置。
- 真实原生对话框、实际参数草稿关闭、多显示器/DPI、干净系统安装与真实跨版本升级仍需对应平台验收。
- 后续测试使用明确配置的公共素材或合成图；禁止个人照片回退。没有独立人工标签，因此不声明商业级选片准确率。原片不会因标记淘汰而被删除。

下载实际附件后按同版本 `SHA256SUMS.txt` 校验，勿沿用 beta2 的校验和。历史 Tag 和附件保持原样。
