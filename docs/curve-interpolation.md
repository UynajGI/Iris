# 曲线插值

## 2026-10-20 默认交互方案修正

交互编辑恢复使用保形 `monotone_cubic`（PCHIP），不再默认启用自然样条。参考 [darktable 的曲线说明](https://darktable-org.github.io/dtdocs/en/darkroom/processing-modules/curves/)：三次自然样条可能过冲、振荡，单调 Hermite 适合维持影调顺序；该软件支持多种插值，并不存在所有摄影软件统一采用的平滑规范。本项目使用同类保形方法，未声称逐像素复刻 darktable、Lightroom 或像素蛋糕。

复现：`(0,0), (0.075,0.7), (1,1)` 的自然样条在 0–1 输入内最高约 2.314，并在高光部分回弯。仅验证二阶连续及裁剪 SVG 绘图区不足以验收调色交互。新编辑采用单调 Hermite，经过每个点、共享节点切线、无区间过冲；它不保证二阶导数连续，也不能让人为挤在角落的强烈调整变成宽缓过渡。

新增交互默认值的形状回归，覆盖强提暗部、压低高光、S 曲线、密集点和平台；逐段验证范围、单调性、SVG 与数值一致及控制点切线连续。原有自然样条继续解释旧版本；只有实际编辑的通道转换，不自动迁移照片。直方图 Y/R/G/B 使用选片与调色共用的组件和样式，移除调色页单独缩到右下角的样式覆盖；RGB 总曲线不改名为 Y。

验证：前端 246 项通过、0 失败、1 项原有跳过，类型检查和构建通过。PPR10K 临时副本 `1025_1025_12.jpg` 的独立“虚拟副本 5”保存约 `(0.074074075, 0.7003367)` 的暗部控制点，后端读回 `monotone_cubic`、修订 1；浏览器内四个直方图通道均为等宽 69.25px。此轮未修改后端算法，未本地编译 Rust。

以下是自然样条试验的历史记录，不能作为当前默认模式说明。

## 2026-10-20 控制点的曲率过渡

新增 `natural_cubic`：自然三次样条在内部控制点保持一阶、二阶导数连续，两端二阶导数为零。此前 PCHIP 只有一阶连续，保形约束可能使控制点两侧的曲率突然改变；新模式用于改善这一弯曲过渡。选型参考 [RawTherapee 的自然三次样条实现](https://github.com/Beep6581/RawTherapee/blob/dev/rtengine/diagonalcurves.cc)，代码按标准三对角方程独立实现，不声称复刻 Adobe 的私有算法。

系数仍按请求预计算，前端 SVG Bézier 段与后端 Hermite 多项式使用相同切线。旧 `linear` 与 `monotone_cubic` 不变；仅实际编辑的通道转换，打开旧文档不重新解释旧参数。自然样条不保证区间内单调或不超调；密集控制点及平台可能回折，图线必须忠实呈现这一结果，不能额外修饰 SVG。FP32 工作值不裁剪到 0–1，区间外仍以端点切线延伸。

新增共享解析样例覆盖三点自然样条、两点仿射、空曲线及负值/HDR 延伸；另以非均匀控制点检查 SVG 与 Rust 多项式的一阶、二阶导数连续性。后端提交 `cdcf4a3` 的 [Verify](https://github.com/UynajGI/Iris/actions/runs/39365135794)、[三平台渲染与烟测](https://github.com/UynajGI/Iris/actions/runs/39365135838)及[优化后端构建](https://github.com/UynajGI/Iris/actions/runs/39365177852)均通过，未本地编译 Rust。

本地编辑器已接入匹配的优化后端，实际编辑通道时使用 `natural_cubic`。SVG 绘图区裁剪越界线段，像素工作值仍保留负值和 HDR。前端测试 245 项通过、0 失败、1 项原有跳过，类型检查和构建通过。PPR10K 临时副本中，`1025_1025_12.jpg` 的独立“虚拟副本 4”完成加点、拖动、保存、撤销和重做，保存后从后端读回确认模式为 `natural_cubic`。原用户页面有未保存草稿，未强制刷新。

以下保留 2026-10-16 的 PCHIP 实现与验证记录；其中不超调、平台保形的性质仅适用于 `monotone_cubic`。

2026-10-16：传统调色曲线增加 `monotone_cubic` 模式。后端与前端数学模块已通过分支 CI 和本地验证；编辑器已接入匹配的优化后端，仍在第一阶段前端开发范围内。

## 计算与兼容

- `Curve.interpolation` 未提供或为 `linear` 时，保留原有线性计算；序列化线性曲线时省略该字段，旧文档的参数形状不变。
- `monotone_cubic` 使用 PCHIP 的保单调三次 Hermite 插值。内部切线取相邻割线的加权调和平均，端点使用受限单边切线。算法依据 [SciPy PCHIP 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html) 所述 Fritsch–Butland 方法。
- 控制点仍限制为 2–64 个，横坐标严格递增、纵坐标非递减；空点集为恒等。曲线经过控制点，平台不产生振荡；这是保单调曲线，不开放反相或回折。
- 区间外沿端点切线线性延伸。负值和 HDR 输入不被统一裁剪到 0–1，端点切线为零时可产生平坦延伸。
- Rust 按请求预计算系数，渲染线程共享系数，像素采样使用分段查找与 Horner 求值。三次曲线走 CPU 路径，未新增 GPU 曲线算子。
- 前端按后端的 FP32 控制点精度和 FP64 切线计算生成 SVG Bézier 控制柄，使图形与实际计算一致；不把旧线性曲线仅在显示上改成平滑线。
- 旧线性曲线在打开、切换通道和单击控制点时保持原样。添加、移动、删除控制点时，该通道转为平滑模式；这次调整进入原有保存/撤销历史。其他通道不被转换。拖动按指针编号跟踪，并应用松开时的最终位置。
