# Iris 交接

更新：2026-10-18。Iris / 伊人为 GPL-3.0-or-later 的本地选片软件，正在独立分支 `codex/color-workflow` 接入传统调色前端。当前源码版本为 `0.1.0-beta5`，此前选片、安装界面、帮助诊断与常用筛选/导出目录改动已随 [PR #19](https://github.com/UynajGI/Iris/pull/19) 合并。已发布安装包仍为 beta3，beta4/beta5 安装包尚未发布。当前授权仅提交、推送开发分支并运行 CI，暂不创建 PR、合并、打 Tag 或发布。见[前端接入](color-frontend-implementation.md)、[颜色分级](color-grading.md)、[后端实现](color-engine-implementation.md)、[CI 记录](ci-verification.md)与[发布流程](releasing.md)。

## 当前实现

- 顶部已加入“导入、选片、调色、修图、导出”导航。传统调色前端已接真实预览/保存、蒙版、历史和成片导出；2026-10-18 加入全局颜色分级色轮与范围混合/平衡，并从生成该合同的 CI 产物同步 OpenAPI 与前端声明。本地前端 244 项通过、1 项原有跳过，类型检查、构建与格式检查通过；真实浏览器使用公开 JPEG 临时副本和该次优化 daemon 验证保存读回、刷新恢复与旧文档默认值。剩余工具及验收见[前端接入](color-frontend-implementation.md)，修图仍为占位。后端为 `iris-render`、schema v9 编辑历史/导出队列及 HTTP/CLI/MCP，FP32 与旧 8-bit 选片预览分开。完整目标见[设计](color-engine-design.md)，后端范围见[实现](color-engine-implementation.md)。Rust 编译交由分支 CI；完整前端阶段尚未完成。

- 后端代码提交 `a05a8a6` 的 Verify 与三平台渲染工作流全部通过；包含完整 Rust 回归、生成契约、媒体、CPU/软件 GPU 对照、并发导出及大图取消释放。测量为 CI 调试构建，尚无真实硬件实时调色性能结论，见[CI 记录](ci-verification.md)。

- 已同步版本与生成 API 契约，并修复启动失败帮助入口、重复导出提示和损坏日志容错。合成浏览器检查覆盖帮助、诊断取消/成功、重试、F1 及失败后清除旧提示；当前验证范围以 CI 记录为准。
- 筛选面板支持命名保存/应用/删除常用组合，本机跨项目共用；仅保存筛选和排序，不携带场景、照片或页码。桌面端导出成功后可打开目标文件夹（CSV 所在目录、XMP 原片目录）；入口不会自动启动文件管理器。见[使用说明](support.md)。
- “帮助与关于”集中版本/构建信息、离线帮助/许可、日志和诊断导出、脱敏错误摘要及手动下载入口。版本同步工具覆盖应用清单和锁文件；[使用与诊断说明](support.md)。默认自动更新保持关闭。
- Windows 安装/卸载向导已接入统一深色控件绘制与简化完成页；浏览器设计稿已确认，本地 Win32 控件测试通过。完整 beta5 安装包与原生视觉验收尚未完成，见[安装器说明](../apps/shell/installer/README.md)。
- 工作台包含画册、单张、组内比较、人脸原图局部检查、技术判断依据、决定/星级/颜色、撤销、任务、设置、模型安装、导出与隔离恢复。设计规则见 [DESIGN.md](../DESIGN.md)，交互与证据见[前端实现](frontend-implementation.md)。
- Windows 原生窗口按钮与顶栏合并；关闭可选择后台运行或退出，支持记住偏好、托盘重新打开与带草稿退出保护。其他平台保留系统窗口装饰，尚未完成对应交互验收。
- 预览解码移出共享服务锁，前台优先、有界预取和过时请求取消；导入并行读取元数据并分批提交。评分先可用，DINO 随后分组；CPU 有界并行，完整 GPU 运行库不可用时恢复 CPU 并行。普通画册在 SQL 中分页。实测及保留问题见[性能验收](performance-plan.md)。
- core/daemon 共享业务逻辑；CLI 与 stdio MCP 编辑工具复用服务。数据库由进程所有权锁保护；MCP 另有目录范围、只读模式和写入审计。见[架构](architecture.md)、[API 契约](api-contract.md)、[MCP 接入](mcp.md)。
- 分析版本仍为 `iris-vision-v7-selection-evidence-2026-10-11`。选片阶段使用 schema v8，当前调色分支新增 schema v9，迁移前保留备份。组内选片意图和照片级必留锁定延续；人工决定与算法建议分开，过期分析保留历史但不作为当前建议。
- 当前照片、比较成员、相邻照片动态影响质量/DINO/检索待处理队列；四次优先领取后保留一次 FIFO，维持后台进度。浏览提示不自动启动任务。
- 场景候选与严格连拍、重复文件分离；支持合并所选、拆出当前照片、恢复自动分组，人工修正跨重建和重启保留。分页范围仍在后端执行。
- 原图区域按需复核、取消并缓存，返回局部图像与独立测量。JPEG/PNG/WebP 使用有界原生解码；RAW/DNG 使用独立转换器的原生区域显影，边界见[媒体支持](media-support.md)。HEIC 细节仍保留预览限制。
- 按项目恢复照片、分页、筛选、场景、比较候选和查看模式，不恢复批量勾选。组内可设置保留数量、锁定必留、显式采纳保留建议；主角人脸和逐张对应纠正持久保存，几何候选不宣称身份识别。
- XMP 使用真实人工星级和颜色，决定单独保存在 `urn:iris:selection:1.0`；更新时保留调色/版权等其他字段与原始备份。外部软件可能忽略 Iris 决定，不再将保留写成五星或将剔除写成负星级。
- 可选本地图文检索默认关闭，无权重自动下载或许可自动接受。兼容双编码器、固定分词器与预处理、可取消索引、指纹失效和覆盖量均已接入；当前精确扫描和查询冷启动的边界见[本地搜索](local-search.md)。
- 独立 RAW 转换器、可选 DINOv3 与 DirectML 保留。可选模型不默认启用，不接受或重新授权模型许可。平台范围见[媒体支持](media-support.md)、[质量缺口](model-quality-gaps.md)。

## 历史选片验收

beta4：一万条合成记录、每条约 18.9KB 分析 JSON、100 张分页，七轮中位数 31.1ms；先完整载入再排序的行为对照为 2173ms，结果 ID 一致。该对照不是单独构建的 beta3 可执行文件。

541 张 PPR 衍生 JPEG 临时副本：本轮导入 645ms、首批 48 项服务可见 171ms、基础 CPU 分析约 38.6 张/秒；浏览器分析期间切图 P95 73ms，冷切图 P95 137ms。应用缓存独立、文件系统缓存和温度未控制；不据单轮结果承诺通用加速倍数。公开人像上的浏览器交互检查覆盖联动/独立视图、原图区域测量、键盘决定、场景合并/退出范围和缺模型提示。不是原生 WebView2、真实检索模型准确率或全分辨率 RAW 验收。

后端完整 workspace 222 项通过、23 项默认忽略；另显式运行的合成 ONNX 双编码器推理与一万条查询测量通过。前端含 PR #17 比较数量边界回归后 109 通过、1 跳过；最终门禁记录见[验证总览](validation.md)。

541 张公共人像的两轮配对测试：导入从 6.18–7.60 秒降为 0.81–1.06 秒；后台加载缩略图时前台预览 P95 从 378–612 毫秒降为 43–45 毫秒；基础分析约 29 张/秒。浏览器分析期间切图 P95 117 毫秒，仍有最高 102 毫秒的主线程长任务。缩小 JPEG 的结果不能推广到全分辨率 RAW、原生 WebView2 或其他机器。

性能阶段 core/daemon 193 项 Rust 测试通过、21 项忽略；前端 104 通过、1 跳过。提交前统一检查见[验证总览](validation.md)。外部模型/媒体忽略项没有计为通过。旧 600 文件回归与 3000 重复条目压力测试属于历史证据，不代表当前人像集或独立场景准确率。

复现入口见[工具索引](../tools/README.md)、[维护检查](maintenance.md)。报告只在忽略目录 `artifacts/`；照片、运行库、权重与私有数据库不进入提交。

## 测试素材

后续演示与测试禁止使用个人照片或回退到 `test-photos/`。当前忽略目录 `reference/test-data/portraits/images/` 有 541 张 PPR10K 衍生 JPEG 人像（90 个原组号，非商业研究条款）和 30 份由 RAF 转换的人像 DNG（29 份不同 RAW 马赛克，仅限来源授权的个人编辑练习）。本轮性能测试只用清单校验过的 PPR JPEG 临时副本。组号不证明连续拍摄时间，没有 500 张 RAW 人像，也没有独立选片准确率金标。

来源、许可、逐文件哈希与视觉复核在本地清单。原 `hdrplus/`、`piq23/`、`rawpixls/` 场景素材已集中到 `reference/待手动删除-旧场景素材/`，等待用户手动删除，不再作为默认测试集。写入、导出与隔离测试仅用可丢弃副本。
