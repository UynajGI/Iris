# 示波器显示约定

调色与选片共用直方图、波形图、分量图和矢量图。分量图显示 RGB Parade。调色工作台的示波器继续固定在工具区上方。

## 专业软件参考

- [Adobe Video Scopes](https://helpx.adobe.com/premiere/desktop/correct-color/color-mode-fundamentals/working-with-video-scopes.html)：波形保留画面横向位置，纵向为信号电平；RGB Parade 将三通道并排、共用刻度；矢量图用方向表达色相、径向距离表达色度。参考其 0–100% 刻度与 75%／100% 色标约定。
- [Adobe Lumetri Scopes](https://helpx.adobe.com/premiere/desktop/correct-color/add-color-effects/available-lumetri-scopes.html)：RGB 叠加、分量图、直方图、色度靶框的用途。
- [ITU-R BT.709-6](https://www.itu.int/rec/R-REC-BT.709/en)，表 3.2–3.3：Y′ = 0.2126R′ + 0.7152G′ + 0.0722B′；Cb = (B′ − Y′)/1.8556；Cr = (R′ − Y′)/1.5748。

## 实现与边界

- 继续测量当前 sRGB 显示预览，最长边 512 像素。不改变浮点调色或高位深导出管线。没有把预览数值称为 RAW 测量、IRE 或 HDR nits。
- 波形与 RGB 分量图使用 0–100% 全范围码值刻度，黑在底部、白在顶部。计数先聚合到显示像素，再用对数亮度显示密度；RGB 分量共用增益，避免每通道自动拉满掩盖密度差异。不把波形拟合成平滑曲线。
- 矢量图将上述色差矩阵用于 sRGB 预览码值，不额外套用 BT.709 OETF 或广播限幅。Cb 向右，Cr 向上；六种基色／补色的 75% 与 100% RGB 色条信号生成靶框。中性灰归中心。靶框是色条参考，不是自然照片必须命中的目标。
- 矢量统计保留密度、不做颜色推断；透明像素不参与统计。所有图继续沿用已经完成的上一帧，等待新帧时不清空闪烁。
- 密度绘制用双线性像素覆盖分配，避免整数取整产生的小方格和摩尔纹；显示增益从零连续起步，没有最低亮度台阶。覆盖分配守恒，端点不丢失；原始统计和裁切比例不参与平滑。
- 直方图与波形保留 Y/R/G/B 叠加开关；RGB 分量固定显示三个通道，矢量图固定显示 Cb/Cr，避免无效开关。
- 移除可见的“预览”来源小字；测量边界保留在无障碍描述与本说明中。

后续影像交互改动先核对专业软件文档或公开实现，写清采用的约定及本软件测量边界，再实现；不把自选视觉效果当成行业规范。
