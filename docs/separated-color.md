# 观察视图与独立影调、颜色调整

更新：2026-10-20。调色工作台顶部提供“全图 / 黑白 / 颜色”三种观察视图。

- 全图：显示完整调整结果。
- 黑白：只显示感知明度，工具区首组为“仅影调”，包含曝光、对比度、高光、阴影、白色、黑色。
- 颜色：把感知明度统一到 0.65，保留颜色分量，工具区首组为“仅颜色”，包含冷暖、色调、色相、饱和度。

普通调整继续可用。两组专用参数分别保存在 `Adjustments.separated.tone` 和 `.color`，与普通参数叠加；切回全图、保存重开、复制调整、预设及导出都保留结果。分别重置专用组不会清除另一组或普通参数；“还原所有调整”仍清空全部。蒙版内的调整同样支持这两组参数。选择性同步分别跟随“影调”和“颜色”组。

观察视图属于窗口状态。前端只在发送预览或原尺寸细节请求时追加临时节点，不修改草稿、历史、预设或导出文档。原图对照使用相同观察方式。原来的黑白处理仍是实际成片操作，界面标为“成片 → 彩色 / 黑白”，与顶部的观察视图区分。

## 运算定义

共享 Rust 渲染器在线性 Rec.2020 D65 工作像素上执行普通调整后，转换至 [Oklab](https://bottosson.github.io/posts/oklab/)：

- 仅影调改变 L，保留 a、b；曝光增益为 `2^(EV/3)`，对比度围绕线性 18% 灰对应的 L 运算，明暗范围遮罩由输入 L 决定。
- 仅颜色改变 a、b，保留 L；冷暖和色调是创意偏色，不是 Kelvin 白平衡。色相旋转 a/b，饱和度缩放色度。
- 两组的范围和偏色强度都从同一个输入 L 计算，避免调整影调时改变颜色组的偏色量。
- 黑白观察输出中性灰；颜色观察固定 L。观察操作在完整编辑图末端进行，能观察蒙版、细节及其他节点叠加后的结果。

默认参数完全跳过转换，保留旧默认文档的序列化与像素恒等路径；有符号立方根保留负值及 HDR，透明像素保留隐藏 RGB，结果沿用有限值与溢出检查。运算按既有有界并行 CPU 管线执行，当前 GPU 曝光路径会对这些参数回退到 CPU。

“保留颜色/明度”指工作空间中的 Oklab 分量。最终显示和导出的色域压缩、裁切及量化仍可能改变显示结果，不能把它表述为显示器上绝对不变的色彩或明度。
