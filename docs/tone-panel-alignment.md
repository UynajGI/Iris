# 传统调色面板与影调修正

2026-10-20。此项接续传统调色工作台，沿用 FP32 线性 Rec.2020 管线。前端布局对照 Lightroom Classic 的功能职责；不宣称复制 Adobe 的私有成像算法。

## 影调算法

旧实现把四个区域的曝光增益相加。高光 -2 时，输入中性亮度 0.5、0.8、1.0 输出为 0.5、约 0.326、0.25，存在明暗反转。本次改用有序明度锚点和 Fritsch–Butland 形状保持三次 Hermite 插值，替换该公式及参数曲线的分区增益。手绘点曲线仍遵循用户选择的插值方式，不强制改成单调曲线。

普通与仅影调使用相同 Oklab L 坐标和映射：黑色移动暗端，高光/阴影移动各自内部锚点，白色移动亮端。中间锚点 L=0.56 保持固定。Iris 的五个输入锚点为 0、0.25、0.56、0.82、1；输出为 0.04b、0.25+0.12s+0.03b、0.56、0.82+0.10h、1+0.07w，其中 b/s/h/w 为各参数的 tanh。它们是公开的实现取舍，不是 Adobe 发布的范围标准。所有允许参数组合均保持严格有序；端点采用受保序条件约束的正切线斜率外推（尽量保持单位斜率，避免压 SDR 高光时反而放大 HDR），保留负值和 HDR 层次，不硬截断到 [0,1]。

普通调整在非零且同号明度上按 RGB 比例缩放；接近或跨越黑位时使用明度变换，避免零除。仅影调保持 Oklab a/b，仍可能因最终显示色域映射产生可见色差。两者中性灰上的效果应一致。普通曝光/对比度与隔离曝光/对比度仍是各自的处理算子。

这次是全局曲线正确性修复，不含引导滤波的空间细节恢复，也不能恢复已经丢失的传感器数据。渲染引擎标识更新为 `iris-render-2-tone`，使旧预览缓存失效。已有非零四区影调及参数曲线设置在重新渲染时外观会变化；参数、历史和原片不被改写，没有保留旧错误算子的可选渲染模式。

回归覆盖：81 组极值/零值组合的负值至 HDR 单调性、连接点一阶连续、黑白端点与中间锚点、真实渲染灰阶渐变及透明度、普通与隔离中性明度一致。旧优化参考继续覆盖未改变的算子，新影调不再与旧错误公式比较。

## 面板及交互

预设入口独立。传统工具顺序为：基础调整、曲线、颜色混合器、颜色分级、细节、光学、变换、效果。

- 基础调整合并原影调/颜色，加入纹理、清晰度、去雾；RAW 白平衡仍使用已有专用入口。
- 细节只负责锐化及降噪。重置细节不重置基础质感。
- 光学管理镜头配置及畸变、色差、光学暗角；变换管理拉直、透视。重置两者均保留裁切。
- 已调整组显示状态点；分组比较按钮只投影临时预览，不写草稿/历史，不影响复制、保存或导出。新参数操作和换版本恢复正常预览。光学比较也临时关闭匹配的镜头配置节点。
- 面板独立展开、收起并记忆状态；不提供单组展开按钮。
- 局部蒙版复用新的分组；其重置只操作对应局部节点，不动全局参数。分组预览对比目前仅提供全局入口。
