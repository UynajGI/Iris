# 帮助、日志与反馈

主窗口右上角的信息按钮或 F1 打开“帮助与关于”。这里提供版本与构建标识、离线使用帮助、
快捷键、当前源码版本说明、GPL 许可证、第三方声明和反馈入口。版本说明及许可随应用打包，
不依赖网络；项目主页、下载页面和反馈页面仅在点击后通过系统浏览器打开。

## 版本与更新

“复制版本信息”包含界面、宿主和后台版本，以及平台、架构、发行方式和构建标识。
版本不一致时提示重新安装完整包。构建来自 Git 提交；构建时已有未提交的跟踪文件修改会标为 dirty，
没有 Git 信息的源码归档标为 source-archive。版本工具见[发布流程](releasing.md)。

默认安装包未启用自动更新；帮助页提供手动下载入口，不自动联网检查或安装。
现有更新协议继续保留，但不会因增加帮助页面而启用更新渠道或接受签名配置。

## 日志与诊断

日志在实际应用数据目录的 `logs/` 内，帮助页显示当前路径并可打开该文件夹。
支持 `IRIS_DATA_DIR` 的已有目录覆盖；Windows 默认数据目录通常位于 `%APPDATA%` 下，
具体目录以应用显示为准。日志目录不可写时明确显示不可用，选片操作继续运行。

- 保存启动、退出、后台连接/重启、前端异常和已观察任务的开始/结束事件。后台标准错误只记为
  `daemon_stderr` 事件；不保存原始 stderr、握手 stdout、照片名称/路径、模型输入或令牌。
- 每个日志约 256 KiB，最多当前文件和三个轮转文件；连续相同事件在两秒内合并。
  不逐张记录照片或每次进度轮询，不自动上传。
- “导出诊断信息”通过系统保存对话框写入 JSON，包含版本、平台、后台可用状态和已验证的事件记录。
  默认文件名含时间与序号，保存窗口明确提示不覆盖已有文件；不收集照片、数据库、环境变量和个人路径。
  日志中损坏或截断的行会被跳过，其余有效事件仍可导出。取消后不写文件。
- 原始错误可在本机展开查看；“复制错误摘要”只复制错误类别、时间和版本，避免将原始路径或凭据带入反馈。
  若摘要不足，请提供复现步骤，并自行确认其他附件中的隐私内容。

日志表示执行过程，不替代照片分析记录。事件受日志体积和保留周期限制，不能承诺记录所有进程崩溃；
系统强制结束和数据目录初始化之前的失败可能没有对应事件。
后台初次启动失败时保留完整“帮助与关于”入口（包括 F1）与诊断命令，允许重试连接；
这些入口不依赖已建立的后台会话。错误面板也可直接导出诊断信息。

## 使用与数据

筛选面板内可“保存当前筛选”，名称为 1–40 字，本机最多 20 个组合；组合在不同项目间共用，
包含标记、星级、颜色、格式、建议及排序。应用组合替换当前筛选，从当前项目第一页开始，
保留每页数量，不携带原项目的场景、照片或页码。重名不覆盖，删除组合不改变当前筛选；
存储失败会显示错误。组合保存在桌面 WebView 的本地存储中，清除应用网页数据会将其清除。

桌面端导出成功后提供“打开文件夹”：复制导出打开目标目录，CSV 打开文件所在目录，
XMP 打开项目原片目录（子目录中的 XMP 仍位于各自照片旁）。只在点击时启动系统文件管理器，
不会自动打开 CSV 或照片。再次导出时清除上次成功提示；导出失败不保留旧的成功提示或目录入口。
位置被删除或磁盘离线时提示错误。

帮助页覆盖扫描和分析的区别、组内比较、标记与撤销、复制/CSV/XMP 导出、隔离恢复及数据备份。
标记剔除不删除照片，隔离操作会移动文件且需要明确执行。备份前先退出应用并复制完整数据目录；
照片原件和隔离文件需另外保管。清理缓存与清除选片数据库是不同操作。

本轮新增的 Rust 日志轮转与脱敏回归由 CI 执行，本地不运行 Rust 编译。
浏览器检查不等同于原生文件保存、系统浏览器启动和正式安装包验收。
