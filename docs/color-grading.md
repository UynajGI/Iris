# 颜色分级：全局、混合与平衡

共享渲染合同和前端入口均已接入。三段色轮继续使用每通道 log2 增益；新增参数可以由全局和局部调整节点共用。所有入口使用同一个渲染实现，选择性同步的“颜色分级”整体复制这些参数。2026-10-18 已用生成该合同的 CI 优化 daemon 在公开样本上联调，边界见[前端接入](color-frontend-implementation.md)。

## 参数和兼容

`ColorBalance` 在 `shadows`、`midtones`、`highlights` 之外增加：

| 参数       | 合同范围            | 中性值    | 界面计划                             |
| ---------- | ------------------- | --------- | ------------------------------------ |
| `global`   | 三通道各 −2…2 stops | `[0,0,0]` | 独立全局色轮及色相、饱和度、亮度数值 |
| `blending` | 0…1                 | 0.5       | 混合 0…100                           |
| `balance`  | −1…1                | 0         | 平衡 −100…100                        |

缺失字段使用中性值；序列化省略中性新增字段，保留旧文档的 JSON 形状及默认参数指纹。新参数非中性时参与既有文档指纹。不会改变三段原有的增益范围，输入必须有限且在范围内。只改变混合或平衡、色轮全部为零时，像素结果仍为恒等。

## 权重

按原有线性 Rec.2020 亮度计算范围位置：`t = clamp(clamp(Y, 0, 1) + balance / 2, 0, 1)`。正平衡使更多像素进入高光范围，负平衡扩展阴影。负值及 HDR 像素只在计算范围权重时限定亮度，工作像素不裁剪到 0…1。

中性混合保留旧三角权重 `[max(1−2t,0), 1−|2t−1|, max(2t−1,0)]`。混合从 50 降到 0 时，连续插值到三角权重的四次方归一化结果，减小相邻范围重叠。混合从 50 升到 100 时，连续插值到二次 Bernstein 权重 `[(1−t)², 2t(1−t), t²]`，让三个范围在区间内部重叠，并保留阴影到高光的方向差异。权重非负、和为 1；最小混合仍是连续过渡，最大混合不是全图统一混色。

三段加权 stops 继续沿用旧阶段位置，随后执行已有黑白混色。全局增益在这之后执行，因此可给黑白结果统一着色；全局为零不改变旧黑白行为。三段本身与黑白混色的既有先后关系保持不变，不宣称已与 Lightroom 的完整黑白分级行为相同。全局及三段均为增益方法，纯零像素不能仅靠增益抬黑。

常量、开关和全局增益按请求预计算；没有范围调整时跳过逐像素权重，所有色轮中性时跳过颜色分级计算。新增权重仅使用少量乘加与归一化，不引入逐像素通用幂函数或额外图像缓冲。曲线、透明度、蒙版混合和输出管理仍沿用原管线。

## 前端接入

2026-10-18：OpenAPI 和前端类型取自生成该合同的 CI 产物，调色面板已启用全局色轮与范围混合/平衡：

- 2026-10-20 按 Adobe 官方颜色分级说明整理为“三轮、阴影、中间调、高光、全局”。三轮总览只有中间调（上）、阴影和高光（下），每轮正下方各有 L 亮度滑块与输入框，范围 −100…100；全局独立分页。悬停或聚焦色轮、滑块时显示 `H:数值 S:数值 L:数值`，预留固定高度避免跳动。读数默认是文字，点击单个数字才原位输入；实时联动，Enter 或失焦恢复文字，Esc 恢复本次输入前数值，空值不写入，范围限制为 H 0…359、S 0…100、L −100…100；单轮页继续常驻 H/S/L 三条滑块及输入框，不重新加入用户已取消的折叠。沿用 Shift/Ctrl/Alt 手势与中性色相记忆；所有视图修改同一套参数。全局轮只写入 `global`，三段增益不变。
- 三轮及三段单轮页下方常驻“混合 0…100”和“平衡 −100…100”，界面值按 100 映射到合同的 0…1 与 −1…1，默认 50 和 0；全局页隐藏这两个仅作用于三段的控件。修改进入草稿；保存后参与历史和撤销，“颜色分级”选择性同步整组复制。
- 渲染端省略中性的新字段，因此旧草稿和新建默认文档都不含它们。界面读取时按渲染端中性值显示；修改某一段或混合/平衡时只写入相关字段，不凭空生成其他字段。服务端序列化仍省略中性字段，旧文档的 JSON 形状和默认参数指纹不变。
- 新增前端检查覆盖中性默认、旧形状读取、非中性往返、五个页签、三轮总览与逐轮亮度及 H/S/L 读数、混合/平衡的显示值，以及渲染面板对旧文档的稳定呈现。真实浏览器保存读回和刷新恢复见[前端接入](color-frontend-implementation.md)。
