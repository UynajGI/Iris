# 选片能力升级计划

日期：2026-10-11。目标：在现有选片工作台上完成组内比较、局部细节复核、判断解释、曝光边界和响应效率五项升级。

## 实施范围与验收

| 顺序 | 工作           | 可交付结果                                                                               | 验收重点                                                                         |
| ---- | -------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 1    | 组内优选       | 共享核心生成组内比较依据，标识接近候选、技术差异与不确定项；前端比较视图显示依据         | 接近分数不强制唯一优胜；分析过期/缺失不参与可靠推荐；不自动标记或删除            |

| 5    | 连续工作性能   | 有界相邻预览预取、当前比较细节按需加载，保持分组焦点；验证重评分复用观察结果             | 快速切换取消无用请求；缓存有界；后台刷新不覆盖人工决定或跳走；记录可复现性能边界 |

## 实施约束

- 使用 core/daemon 的共享判断规则，桌面、CLI、MCP 可获得相同证据；变更契约后重新生成 OpenAPI 与前端声明。
- 沿用 DESIGN.md 的工作台与状态语义，只增加选片所需的操作和信息。
- 分组相似度、技术分差和人脸位置不作为校准概率、身份识别或审美判断。
- 本轮不接受新模型许可，不引入云推理，不修改授权源照片；浏览器验证仅使用临时副本。
- 不扩大成调色器、通用节点编辑器或完整色彩管理系统。RAW 原始数据恢复评估、跨图身份匹配和人工独立标签评估单独记录边界。

## 嵌入模型决策

当前保留既有可选 DINOv3 ViT-S/16 视觉嵌入、时间窗口与感知哈希候选筛选，不新增图文模型或向量数据库。图文嵌入用于自然语言检索，尚不是这五项选片能力的依赖。跨照片人物身份关联与中文搜图应有独立需求、许可核对和检索评测；相似度阈值不等于重复证明，模型宣传延迟不作为 Iris 的验收结果。

## 验证计划

1. 核心行为测试：组内接近候选、缺失观察、无脸照片、创意曝光、闭眼与严重缺陷。
2. 前端状态与交互测试：局部区域坐标、选择切换、预取有界与取消、分组刷新稳定。
3. 类型检查、Rust 检查与相关测试、前端构建、契约一致性、复杂度和公开源码边界检查。
4. 一轮桌面尺寸与 800×560 浏览器检查，必要时集中修复后一次确认；不将浏览器结果等同于原生多平台验收。
5. 完成后在此记录实际结果、未验证项及后续边界；不得把忽略或未运行的测试计为通过。

## 已实现行为与边界

- core 统一输出单片证据和组内比较；组内技术分差不超过 5 分保留接近候选。这是可解释启发式，不是校准概率或审美排名。过期、缺失、不可用分析不作比较基准，闭眼与证据不足保持人工复核；相对比较基准可以仍是单片“待复核”。不会自动改写人工标记。
- 比较视图可为每张照片独立选择从左到右排列的人脸，按脸部大小对齐。JPEG/PNG/WebP 在不超过 60MP、64MiB 时按需读取原图；失败、方向比例不符、RAW/HEIC 或超预算时明确保留预览。未实现跨图人物身份对应、RAW 全分辨率脸部解码或原图局部重新推理，指标仍来自既有预览。
- 观察结果、证据限制、创作语境分别提供结构化代码；无人脸照片具备技术推荐路径，未检出人脸不推断照片没有人物。闭眼仍只建议复核。
- 曝光技术分不再因平均亮度偏离中灰直接扣分。阴影/高光裁切是预览观察，不等同 RAW 不可恢复；RAW 预览不触发严重质量的拒绝建议。分析版本升级到 v7，技术评分与局部脸部评分方法均更新为 v2。
- 相邻预览在停留 150ms 后预取最多 2 张；媒体请求共享，闲置缓存限制为 24 项/32MiB 的压缩内容，原图最后一个使用者离开即释放。活动请求/解码图像不计为受此上限约束的总进程内存。照片修订参与缓存标识，离开页面取消无用请求；仍复用已有模型观察进行重评分。
- 未进行个人工作站推理延迟、整机峰值内存、检索准确率或独立人工标签评测；不承诺模型宣传中的毫秒耗时，也不新增模型下载、许可接受或远程推理。
