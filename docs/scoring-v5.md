# v5 技术质量评分

版本说明：本文记录v5引入并由当前v6保留的评分规则；下文v5标识是历史分析版本。当前缓存身份、默认预测回归和未完成验收见[交接](HANDOFF.md)，不是要求将当前代码退回v5。

这是可解释的技术观测启发式，不是经人工偏好训练或校准的人像质量模型。
这些规则最初使用分析版本 `iris-vision-v5-observed-quality-2026-10-07`；当前分析版本为 `iris-vision-v6-local-pipeline-2026-10-07`。版本更新需要重新分析旧照片，
不能用旧记录缺失的局部人脸观测伪造新评分；人工保留/拒绝决定独立保存。

## 清晰度

原始 Laplacian 方差为 `lap`，128×128 Hann 窗频谱中高频能量占比为 `fft`。
映射和组合为：

```
L = clamp(100 × ln(1 + max(lap, 0)) / ln(1001), 0, 100)
F = 100 × sqrt(clamp(fft, 0, 1))
B = 0.75 × L + 0.25 × F
N = clamp(100 - 12.5 × max(NIQE - 2, 0), 0, 100)
S = (1 - niqe_weight) × B + niqe_weight × N
```

最后一行仅在NIQE启用且可用时使用，否则 `S = B`。默认NIQE内部权重0.2，
因此可用时Laplacian、FFT、NIQE分别占清晰度类别的60%、20%、20%。
平方根映射和混合比例是明确的设计选择，不能解释为测得的摄影偏好概率。
FFT现在实际影响评分；旧版只存储该数值。

纹理和噪声均可能抬高Laplacian与FFT。NIQE并不保证消除该影响，低纹理但清晰的照片
也可能得到低值。受控模糊实验可以验证响应方向，不能证明照片排序准确或抗噪能力。

## 人脸技术质量

`Face.confidence`继续表示检测置信度，不参与人脸质量类别。`Face.quality`使用
EXIF方向校正、最长边有界的分析预览上实际检测框裁剪，裁剪不放大。
有效区域须至少3×3像素；无效框、无有效交集或过小区域没有伪造分数，而是返回缺失原因。

```
local_L = 与全图相同的Laplacian映射
local_E = clamp(100 - 60 × abs(mean - 128)/128
                - 70 × (shadow_clip + highlight_clip), 0, 100)
R = 100 × clamp(min(crop_width, crop_height) / 128, 0, 1)
Q = 0.50 × local_L + 0.30 × local_E + 0.20 × R
```

128像素参考尺寸、混合系数与曝光映射都是技术启发式常量。脸部类别取有效 `Q` 的均值，
同时报告观测覆盖数。头姿单独报告；这里不把正脸当作审美标准，也不把掩膜或检测置信度
误当作整体人脸质量。眼态与表情继续属于独立类别。框内背景和纹理、预览缩放以及多人脸
大小分布都会影响此分数；它不涵盖身份、表情偏好、美学或通用遮挡准确率。

## 评分明细与兼容性

五类配置权重保持：眼睛25、清晰度25、人脸质量20、构图/曝光20、微笑10。
每类明细包含配置权重、实际生效权重、分数、归一后的贡献与缺失原因。
无观测类别不补零，其权重不进入有效权重总和；贡献总和等于综合分数。
所有原始测量、映射项与内部组合权重均可检查。保守眼态门禁、闭眼仅触发复核、
严重技术缺陷才建议拒绝的规则保持。

新增字段可选，以便读取历史记录。旧版本读取不等于当前版本有效；服务端逐张
`analysis_status`区分 `missing`、`current`、`stale`。过期数据不应被前端当作新评分，
也不能用于可采纳建议或伪造配置预估。重评分不会自行升级分析版本。
