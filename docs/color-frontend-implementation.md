# 传统调色前端接入

更新：2026-10-16。`codex/color-workflow` 正在开发第一阶段传统调色前端；这是首批接入记录，不是整个调色阶段的完成声明。修图工作区仍为占位。后端合同与限制见[后端实现](color-engine-implementation.md)，完整目标见[设计](color-engine-design.md)。

## 当前已接入

- 沿用顶部居中工作流、深色工具区和中性照片底。照片、胶片栏与版本共享选片上下文；历史入口位于右上角。右侧分为调色、蒙版、信息三页；调色参数继续分组折叠。整个颜色管理页迁至“导出 → 高级”，默认折叠。
- 影调、创意冷暖/色调、饱和度、HSL、RGB/参数曲线、阴影/中间调/高光颜色分级、黑白混色、细节、颗粒、暗角，以及画布裁切/透视/光学校正。颜色分级通过明暗范围切换操作 200px 大色轮，保留色相、饱和度、亮度精确输入；色轮操作既有三段增益合同，不维护第二套算法参数，旧编辑可读回色轮并保留参数。本地检查覆盖范围切换、鼠标拖动、键盘微调与撤销恢复，类型检查及 7 项控件测试通过。
- 裁切支持自由、原始比例、1:1、4:5、3:4、2:3、9:16 及横竖切换；可锁定当前框比例。角点固定对角、边缘围绕另一轴中心缩放，拖动范围限制在源图内。比例选择和重置只修改裁切矩形，不重置透视、光学或调色。
- 全局调色预设支持从当前草稿新建、重命名、删除及分页读取，持久化使用共享 daemon 预设服务。应用通过既有面板绑定更新全局影调/颜色/细节，保留目标的裁切、光学、RAW 白平衡、局部蒙版和输出设置；应用先进入草稿，保存后可撤销。此入口不包含任意节点图预设，复杂图会明确拒绝应用，避免静默丢失节点。
- 画笔、线性/径向渐变、亮度/颜色范围蒙版，局部影调/颜色/细节、反选、强度和启用/删除。画笔与渐变在照片坐标中绘制；空间蒙版按后端定义即时绘制红色透明度覆盖，支持显示开关。颜色/亮度范围及其组合通过 `mask-preview` 读取蒙版节点输入的线性 Rec.2020 代理并复用后端蒙版算法，以带透明度的 PNG 显示覆盖；不从显示 JPEG 反推权重。覆盖图只供查看，不写入工作像素、导出或历史，仍是有界代理采样而非原尺寸覆盖率测量。
- 同一蒙版内支持添加、减去、相交，以及组成列表选择和移除。画布与范围参数编辑所选组成，保留其他分支、反选和透明度包装；红色覆盖显示最终空间组合，局部调色仍绑定整个蒙版。画笔擦除限定在选中的笔刷组成内。深度、节点和画笔点数继续遵守后端预算，不放宽限制。
- 已保存版本与草稿预览分开。连续输入使用单个在途轻量预览与最新待处理参数，避免不断取消导致画面饥饿；停止输入 300ms 后补 1600 边长预览，重新操作可取消清晰度补帧。照片/版本变更拒绝旧结果，失败保留草稿。保存使用版本检查和请求回执；撤销/重做、虚拟副本复用同一后端编辑文档。
- 原图比较重新调用高精度源节点和同一输出变换。工作计算不经过选片 JPEG 缓存；浏览器仍以最终 JPEG 显示。
- 工具栏“1:1”按一个输出像素对应一个屏幕物理像素查看当前草稿，支持拖动、方向键和缩略导航定位。区域坐标采用全部调色/几何之后的真实输出尺寸；高 DPI 下按像素比换算，超大窗口将细节视口限制在后端 4MP/2048 边长预算内，保持原尺寸而不缩小区域。拖动或参数更新先显示预览，停顿 350ms 后读取真实细节，仅在返回图像解码完成后显示“1:1”；错误可重试，切图/版本取消旧请求。进入原图比较、裁切或蒙版编辑时回到普通画布。
- 原尺寸接口支持草稿和归一化视口中心，不写入版本或历史；保留已有绝对区域调用。当前仍需全分辨率计算整个节点图后提取区域，属于有界内存的完整求值，不是 ROI 加速；浏览器图像为最终 sRGB JPEG，原尺寸表示空间采样比例，不代表无损或 HDR 显示。全分辨率 RAW 的持续拖动速度和原生多屏 DPI 尚待验收。
- RAW 白平衡独立折叠面板提供开尔文色温、色偏、拍摄时与日光/阴天/阴影/白炽灯预设，以及中性灰吸管。读取和计算复用后端相机校准，参数只写入当前草稿的传感器增益，保存后参与撤销/重做；打开已有版本从增益反算控件，无法表示时不编造默认色温。吸管暂时显示未裁切原片，按源像素取 8×8 区域，支持键盘移动/确认/取消；取样后回到当前裁切画面。原图比较恢复拍摄时白平衡。
- RAW 白平衡采用现有单 D65 相机矩阵与 Planckian 轨迹模型；色偏界面的 -100…100 对应 CIE 1960 v 偏移 -0.02…0.02，不是 Adobe 的 Tint 或垂直 Duv 标尺。没有双光源 DCP 插值或厂商配置外观，不能以数值一致声称对齐 Lightroom 的显影。JPEG 的冷暖/色调仍为渲染 RGB 的相对调整。
- 页面离开与原生关闭保护接入调色 dirty 状态。预览热刷新在有未保存参数时延后，保存后恢复；评审环境记住当前项目、照片和页面。
- 成片导出以选中的已保存版本为基础，支持 JPEG8/PNG16/TIFF16、状态轮询、取消/重试和恢复；既有原片复制/CSV/XMP 导出仍独立显示。高级设置产生仅供本次导出的文档快照，不保存到照片版本或调色历史；后端校验源身份和基础修订，并固定资源副本，保留重试/恢复语义。源 EXIF 继承仍遵循后端当前限制。
- “导出 → 高级 → 颜色管理”支持 sRGB、Display P3、Adobe RGB、线性 Rec.2020，以及高光柔和压缩和目标色域压缩。展开后提供调整预览与独立 ICC 软打样；普通预览统一按 sRGB 显示，目标设备模拟使用所选 ICC 打样，不将普通预览宣称为导出文件的色域校样。
- 导出高级颜色管理可导入/替换 1D、3D `.cube` LUT，切换输入色域（非线性 sRGB 或线性 Rec.2020），开关、调整强度和移除。复用后端资源校验与独立 LUT 节点；自定义图中的其他 LUT 不被接管或重排。文件格式、32 MiB 限制和资源校验失败保留原有设置。此入口不包含相机 Log 转换或完整 LUT 资源库管理。
- 导出高级颜色管理接入 ICC 软打样：导入/替换 `.icc`、`.icm`（最多 16 MiB），启用、关闭和移除。使用同一有界渲染队列预览导出快照，切换配置拒绝旧结果，只有实际打样图返回后显示标记。使用后端相对比色、sRGB 显示变换；打样不会写入编辑图、历史或导出色域。尚无纸张/墨色模拟开关、渲染意图选择或系统显示器配置管理。
- 信息页按需读取相机、镜头、光圈、快门、ISO、焦距与拍摄时间；更多信息包含等效焦距、曝光补偿、曝光模式、测光、白平衡模式、闪光灯、拍摄者及版权。选片元数据折叠区复用同一组件，折叠时不请求拍摄信息；切图和关闭面板取消旧请求。缺失、不可读和超出 16 MiB 读取范围分别说明，不推测字段或时区。并非完整厂商 MakerNote 浏览器，也不写入或继承 EXIF。
- 几何与光学提供镜头配置文件导入和后端 EXIF 精确匹配入口；匹配的校正放在未裁切源图之后，保留用户裁切、透视和局部节点。当前只支持 Iris 已定义的校准 JSON，尚无内置镜头库、Lensfun/Adobe LCP 适配或 RAW 默认自动开启，不能宣称覆盖 Lightroom 镜头配置库。

实现入口：[工作台](../apps/shell/src/ui/color/ColorWorkspace.tsx)、[编辑会话](../apps/shell/src/ui/color/useColorEditor.ts)、[API 客户端](../apps/shell/src/editing-client.ts)、[节点参数](../apps/shell/src/editing-document.ts)、[蒙版图](../apps/shell/src/editing-masks.ts)。面板只改其绑定节点，不把任意节点图压平为另一套参数。

## 2026-10-16 选择性同步

共享服务新增 `POST /api/v1/edits/{id}/sync`：调用方明确指定源版本、目标版本及各自修订号，可选择影调、颜色、曲线、颜色分级、细节、效果、裁切/透视、光学校正。仅修改所选传统面板参数，保留原片绑定、RAW 传感器白平衡、蒙版、LUT、输出配置及其他节点。裁切和光学为独立选项，不能随颜色默认覆盖。整批使用一个事务；重复请求绑定整批输入并基于原目标快照重放，后续撤销不会被重试覆盖。

调色工具底部提供“同步…”窗口，默认选择六组全局调色参数，裁切与光学默认不选；目标为当前胶片栏中明确勾选的 1–100 张照片。多个虚拟副本需要明确选择版本，读取以四路并行执行。未调色照片在确认后先建立初始版本；这些初始版本的建立与最终参数同步分开，准备失败时可能保留空白初始版本，必须刷新再选，不自动重建。打开/取消目标选择不创建目标版本。网络结果不明时保留原请求重试，明确拒绝则要求刷新；每张照片历史保留独立撤销入口。

实际联调使用 `7b51ca4` 的[优化后端与三平台渲染 CI](https://github.com/UynajGI/Iris/actions/runs/38888946254)：两张 PPR10K 临时副本只同步影调，读回确认裁切、蒙版、颜色参数和原片绑定保留，源版本及三个原图文件哈希不变；另一张未调色照片成功建立初始版本并同步。人为制造第二个目标修订冲突后，第一个目标修订不变，整批回退，前端出现刷新入口。该提交的 Rust 工作区测试已通过，完整 Verify 与后续前端提交状态单独跟踪。当前本地前端 198 项通过、0 失败、1 项原有跳过；类型检查和热更新构建通过，800×560 窗口的同步操作区保持可见。

当前限制：需要可达且唯一的传统面板绑定；目标面板禁用时要求先启用，避免同步时意外激活未选择的旧参数。跨相机 RAW 白平衡换算和蒙版跨图迁移不在本接口范围。既有整图配方接口仍独立保留，不作为选择性同步的实现。

## 本地预览

先运行 `npm --prefix apps/shell run build`，再分别启动 `node tools/watch-frontend.mjs` 与 `node tools/preview-frontend.mjs`。预览为 `http://localhost:1420/`；watch 只构建前端。

评审服务必须明确设置 `IRIS_REVIEW_DATASET=ppr10k` 或 `piq23`、`IRIS_REVIEW_PHOTOS` 和可选 `IRIS_REVIEW_DAEMON`（指向 CI 下载产物）。`node tools/review-bootstrap.mjs` 只为运行中的临时评审副本扫描建库。

更新 daemon 时可用 `IRIS_REVIEW_WORKSPACE` 复用既有临时评审目录：目录必须位于系统临时目录内、名称以 `iris-ui-review-` 开头，照片字节须与明确配置的公共源样本逐张相同。已保存编辑和导出日志因此得以保留。不要复用个人照片目录或生产数据库；照片、模型、CI 可执行文件与浏览器报告均不提交。
