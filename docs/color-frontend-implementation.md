# 传统调色前端接入

更新：2026-10-16。`codex/color-workflow` 正在开发第一阶段传统调色前端；这是首批接入记录，不是整个调色阶段的完成声明。修图工作区仍为占位。后端合同与限制见[后端实现](color-engine-implementation.md)，完整目标见[设计](color-engine-design.md)。

## 当前已接入

- 沿用顶部居中工作流、深色工具区和中性照片底。照片、胶片栏、版本、历史与折叠工具面板共享选片上下文；窄窗口保留版本选择和历史入口。
- 影调、创意冷暖/色调、饱和度、HSL、RGB/参数曲线、三段颜色增益、黑白混色、细节、颗粒、暗角，以及数值裁切/透视/光学校正。
- 画笔、线性/径向渐变、亮度/颜色范围蒙版，局部影调/颜色/细节、反选、强度和启用/删除。画笔与渐变在照片坐标中绘制；当前绘制辅助线不是精确的蒙版覆盖率可视化。
- 已保存版本与草稿预览分开；拖动请求合并、过时请求取消、失败保留草稿。保存使用版本检查和请求回执；撤销/重做、虚拟副本复用同一后端编辑文档。
- 原图比较重新调用高精度源节点和同一输出变换。工作计算不经过选片 JPEG 缓存；浏览器仍以最终 JPEG 显示。
- 页面离开与原生关闭保护接入调色 dirty 状态。预览热刷新在有未保存参数时延后，保存后恢复；评审环境记住当前项目、照片和页面。
- 成片导出读取已保存版本，支持 JPEG8/PNG16/TIFF16、状态轮询、取消/重试和恢复；既有原片复制/CSV/XMP 导出仍独立显示。源 EXIF 继承仍遵循后端当前限制。

实现入口：[工作台](../apps/shell/src/ui/color/ColorWorkspace.tsx)、[编辑会话](../apps/shell/src/ui/color/useColorEditor.ts)、[API 客户端](../apps/shell/src/editing-client.ts)、[节点参数](../apps/shell/src/editing-document.ts)、[蒙版图](../apps/shell/src/editing-masks.ts)。面板只改其绑定节点，不把任意节点图压平为另一套参数。

## 本轮证据

- 本地前端类型检查与构建通过；一次完整前端构建约 2 秒，不包含 Rust 或 Tauri 原生编译。
- 前端测试 150 通过、0 失败、1 项原有检查跳过；新增测试覆盖绑定节点、蒙版分支/删除、颜色空间、请求认证/版本、原图比较、重置及组内导航。
- 真实浏览器连接 CI 构建的 Windows daemon，使用 12 张明确配置的 PPR10K 衍生 JPEG 临时副本。全局 +0.75 EV 与线性蒙版局部 +0.5 EV 分别保存；撤销移除局部分支、重做恢复，源绑定不变。
- 未保存参数离开页面出现保护对话框，继续编辑保留数值。TIFF 实际输出的四通道均为 16 位，含 ICC；输入照片与公共源样本 SHA-256 相同。
- 后端源码 `789375f` 的 [Verify](https://github.com/UynajGI/Iris/actions/runs/38850698946) 与[三平台渲染](https://github.com/UynajGI/Iris/actions/runs/38850698924)通过，包含 rustls 补丁更新。当前本地联调 daemon 来自该 CI 产物，没有本地编译 Rust。

这些检查不等于摄影画质金标、全分辨率 RAW 性能或完整原生桌面交互验收。浏览器的目录选择/原生命令使用评审替身，渲染、保存和导出调用真实后端。

## 继续接入

1. RAW 物理白平衡/中性吸管、镜头配置导入与匹配、LUT/ICC 资源及软打样、输出颜色空间设置。
2. 预设与选择性批量同步。应明确处理每张图的原片白平衡与已有局部节点，不能把整图配方替换冒充选择性同步。
3. 原尺寸区域查看、交互裁切、完整蒙版组合/覆盖率查看与色轮；当前放大倍率相对于适合窗口，不是原片 1:1 像素承诺。
4. 完整拍摄元数据：相机、镜头、光圈、快门、ISO 等。当前面板仍只有既有文件信息和可读取的拍摄时间。
5. 草稿断线恢复、原生关闭与更多窗口/字号组合验证；真实硬件响应测量按实际瓶颈安排。

## 本地预览

先运行 `npm --prefix apps/shell run build`，再分别启动 `node tools/watch-frontend.mjs` 与 `node tools/preview-frontend.mjs`。预览为 `http://localhost:1420/`；watch 只构建前端。

评审服务必须明确设置 `IRIS_REVIEW_DATASET=ppr10k` 或 `piq23`、`IRIS_REVIEW_PHOTOS` 和可选 `IRIS_REVIEW_DAEMON`（指向 CI 下载产物）。`node tools/review-bootstrap.mjs` 只为运行中的临时评审副本扫描建库。

更新 daemon 时可用 `IRIS_REVIEW_WORKSPACE` 复用既有临时评审目录：目录必须位于系统临时目录内、名称以 `iris-ui-review-` 开头，照片字节须与明确配置的公共源样本逐张相同。已保存编辑和导出日志因此得以保留。不要复用个人照片目录或生产数据库；照片、模型、CI 可执行文件与浏览器报告均不提交。
