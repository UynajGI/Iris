# 节点调色工作台

2026-10-20，开发分支 `codex/color-workflow`。普通校正节点承载整套调整，不再按“调色 / 细节 / 几何”选择节点类型。传统面板和节点面板编辑同一个 `EditDocument`，切换界面不重排、展平或自动保存另一份文档。

## 操作

- “添加节点”在选中图像节点之后插入普通节点；曝光、颜色、曲线、HSL、颜色分级、细节、光学和变换在同一节点内编辑。画面裁切、蒙版和调整复制粘贴跟随选中节点。
- 绿色圆端口传递 RGB 图像，蓝色三角端口传递 Key 选区。拖动输出到输入，或依次点选两个端口接线；Esc 取消。已有连线和拖动引导均为直线。
- “并行”建立共同输入的另一条校正分支及并行混合节点；“图层”建立分支并按前景覆盖背景合成。添加后选中新分支。删除自动生成的分支会收回其二输入混合节点并保留另一支。
- Key 输入可连接其他节点的选区；右键 Key 输入恢复全选。最终输出提供独立 RGB 和 Alpha 输入，右键 Alpha 断开输出选区。导出带 Alpha 的 PNG/TIFF 才会保留透明度；JPEG 预览会使用输出背景合成。
- 眼睛按钮或画布内 Ctrl+D（macOS Cmd+D）旁路当前校正，不清空参数。为保持合流的图像与 Key 坐标一致，节点尺寸/几何仍保留；这是目前与 Resolve 完整节点旁路的差异。
- 画布内 Alt+S / Alt+P / Alt+L 分别添加串行、并行、图层节点；Delete 删除所选用户节点。输入数值或名称时不触发这些快捷键。拖动标题移动节点，空白处平移，滑轨缩放，“适合”显示全图。

交互参照 [Blackmagic Design Color 工作流](https://www.blackmagicdesign.com/products/davinciresolve/color) 和官方 [Resolve 参考手册](https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_11_Reference_Manual.pdf) 中 Serial, Parallel, and Layer Nodes、Managing the Node Editor。采用其普通校正节点、图像/Key 端口和分支操作模型；不声称混合数学、每项工具或全部高级功能与 Resolve 完全相同。

## 文档与执行

用户看到的普通节点由 `corrector:<uuid>:<part>` 面板绑定分组。内部仍使用独立几何、调色、细节、蒙版、Key 混合及图像混合算子，统一进入 Rust DAG。组内算子在画布中隐藏，用户不需要理解它们来添加节点。

旧基础链和先前创建的三算子组可直接打开，不自动写回。首次需要 Key、分支或旁路时才补全组：保留原算子及其顺序，增加共享几何的底图分支和 Key 合成。默认全选时输出与升级前一致。传统面板修改旧组几何时同步底图分支，避免坐标失配。分组身份以原调整算子保持稳定，升级不会重排显示编号。

颜色与选区端口类型、缺失输入、循环、节点数量和合流几何一致性在前端提交前检查，Rust 编译图再次检查。空间变换不一致时明确拒绝合流，不偷偷拉伸蒙版。完整图和布局随现有自动保存、历史撤销恢复及导出保存。

新节点的默认全白 Key 不应分配多幅全尺寸蒙版。执行阶段将常量全白/全黑 Key 的混合替换为对应图像引用，省去无效处理；该优化不改写持久化图。
