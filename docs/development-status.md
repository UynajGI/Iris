# 当前开发状态

更新：2026-10-12。下一版本为 `0.1.0-beta3`，发行准备与边界见[beta3 说明](releases/v0.1.0-beta3.md)。

| 功能                                   | 状态                                                                          |
| :------------------------------------- | :---------------------------------------------------------------------------- |
| 多格式、RAW、DINO 缓存、DirectML       | 已实现；媒体与 GPU 覆盖边界另列                                               |
| 画册、单张、组内比较、标记、导出与恢复 | 已接入真实服务；支持人脸局部检查与技术判断依据                                |
| 导入、预览与分析速度                   | 有界并行、前台优先、评分先可用；541 人像验收见[性能记录](performance-plan.md) |
| Windows 窗口与后台运行                 | 原生按钮、关闭偏好、托盘与退出保护已实现；本机定向验证通过                    |
| CLI / HTTP / WS / MCP                  | 共享核心服务；44 个 stdio MCP 工具，目录边界与写入审计                        |
| macOS/Linux                            | 保留系统窗口装饰；HEIC/ExifTool 与原生交互仍有缺口                            |
| 安装器与发行                           | EXE、双架构 PKG、DEB 和便携包流程已有 beta2 CI 证据；beta3 尚待跨平台发行验收 |
| 签名与自动更新                         | 正式签名、公证和更新渠道未配置                                                |

测试通过不等于选片准确率达到商业标准。当前性能集为 541 张缩小 JPEG 人像；历史 3000 条目来自 100 张照片重复 30 次，不能算独立场景。

入口：[验证总览](validation.md)、[前端实现](frontend-implementation.md)、[架构](architecture.md)、[质量缺口](model-quality-gaps.md)。待办见 [HANDOFF.md](HANDOFF.md)。
