# 选片功能补齐计划

基线：PR #17 合并提交 `f3732d8`，源码 `0.1.0-beta4`。开发分支：`codex/selection-workflow`。

本轮只开发功能缺口与修复。真实照片上的准确率、主观判断和整机性能体验由用户使用反馈，不作为本轮新建评估项目。保留修改所需的自动回归；Rust 编译与回归交给 CI，不在本机重新编译。演示和测试仍禁止个人照片。

## 完整交付范围

1. **XMP 导出修复**：星级和颜色来自人工标记，不再把保留一律转成五星；决定与星级分别保存。更新已有 XMP 时保留原有调色、版权及其他字段，兼容命名空间别名、属性与元素表示；损坏文件拒绝覆盖。相同 RAW/JPEG 共用 sidecar 时检查全部导出标记是否一致，保留原文件与备份。
2. **选片现场恢复**：按项目保存当前照片、筛选、场景、比较候选及查看模式；重新打开后恢复。旧照片、失效场景、缺失文件和超过比较数量上限的记录安全收敛；切换项目、异步读取和退出不能串用现场。
3. **RAW/DNG 原图细节**：复用独立 RAW 转换器按需获取原生分辨率区域，接入现有细节查看；支持取消、有界资源和指纹缓存。明确转换失败与预览回退，避免仅把预览放大当作原图细节。
4. **组内保留数量与锁定**：用户指定每组目标张数，并锁定必留照片；重新推荐保留锁定项，从剩余当前有效候选补齐。不暗中修改人工决定；锁定数量超标、候选不足和分析缺失有明确状态。设置与锁定跨重启保存，组重建不丢照片级锁定。
5. **主要人物选择**：允许选择本组关注的人脸，组内比较优先展示对应脸部、眼睛和清晰度。复用已有几何对应与人工选择，不将位置对应宣称为身份识别；不确定对应允许逐张校正并保存。清除、分析失效、组变化和无人脸都有可恢复状态。

## 顺序与验证

- 先修 XMP，再完成现场恢复；随后接通 RAW 细节和组内选优、主要人物选择的共享后端与前端入口。
- 合同变化时同步 OpenAPI 与前端类型，更新用户文档；不增加自动模型下载或自动许可接受。
- 每项保留针对行为边界的回归：元数据保留与冲突、现场恢复与过时响应、取消/缓存、数量/锁定、人物对应/失效。CI 未运行或未通过不得计为完成。
- 本轮不自动发布安装包、打 tag 或合并 PR。所有五项实现和必要验证完成后，才将目标标记完成。
